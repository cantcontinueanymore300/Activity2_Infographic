# Activity 2 - Information Technology Infographic

## Description

This project is a two-page infographic related to Information Technology.

### Page 1: Impact to Society

The first page presents the positive and negative impacts of Information Technology on society. It focuses on communication, education, privacy, and cyberbullying.

### Page 2: Student Course Comparison

The second page presents an illustrative comparison of student distribution across selected computing courses:

- BS-CS — 40%
- BS-DS — 25%
- BS-IS — 20%
- BS-IT — 15%

The percentages are illustrative data created for infographic purposes.

## Format

The infographic consists of two pages with a 1080 × 1350 px aspect ratio.
